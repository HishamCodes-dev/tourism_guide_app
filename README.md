تطبيق الدليل السياحي (Tourism Guide App)
تطبيق هاتف ذكي متعدد المنصات مطوّر باستخدام إطار العمل Flutter ومرتبط بخدمات Firebase، يهدف إلى مساعدة المسافرين والسياح في استكشاف الوجهات السياحية والمعالم الأثرية وتخطيط رحلاتهم بسهولة.

نظرة عامة
يقدم التطبيق دليلاً منظماً لأبرز المدن، المعالم التاريخية، المتاحف، والأماكن الطبيعية والترفيهية. يعتمد التطبيق على واجهة مستخدم بسيطة وسريعة الاستجابة، مع مزامنة البيانات لحظياً عبر الخدمات السحابية لتوفير تجربة استخدام سلسة وموثوقة.

المميزات الرئيسية
نظام المصادقة وإدارة الحسابات: إمكانية إنشاء حساب جديد، تسجيل الدخول، واستعادة كلمة المرور بأمان عبر Firebase Authentication.

استكشاف الوجهات السياحية: عرض قوائم منظمة للأماكن السياحية مصنفة حسب المدينة ونوع النشاط.

البحث والتصفية المتقدمة: محرك بحث سريع يتيح الوصول لأي معلم سياحي بالاسم أو تصفية النتائج حسب الفئة.

عرض التفاصيل الشاملة: صفحة مخصصة لكل معلم تعرض نبذة تعريفية، معرض صور، الموقع الجغرافي، وأبرز المعلومات التي تهم الزائر.

قائمة المفضلة: إمكانية حفظ الأماكن المفضلة في حساب المستخدم للرجوع إليها في أي وقت.

التقنيات والأدوات المستخدمة
تطوير التطبيق: Flutter & Dart

الخدمات السحابية وقواعد البيانات: Firebase (Authentication, Cloud Firestore, Firebase Storage)

إدارة الحالة (State Management): Provider / Bloc

هيكلة المشروع: تقسيم الملفات بشكل معياري (Modular Architecture) لسهولة الصيانة والتطوير.
